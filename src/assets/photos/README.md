# Photographs

Drop photos here named after the slot they fill (`.jpg`, `.jpeg`, `.png`, `.webp` or `.avif`).
Astro resizes and optimises them automatically. Until a file exists, the site shows a placeholder
labelled with the slot name, so you can see exactly where each image goes.

Recommended: landscape images at least 2400px wide for heroes, 1600px for everything else.
